# 《生态纪元》首次游玩流程

本文档规定玩家第一次打开游戏时的体验节奏。目标是确保第一局像一款有主线的放置演化游戏，而不是控制面板。

## 1. 体验目标

新玩家应在最初 3 秒内理解：

```text
我要把这片没有生命的潮池，养出第一只生命。
```

第一次操作前应理解：

```text
把发光的养料拖进水里。
```

## 2. 时间节奏

| 时间 | 玩家看到 | 设计目的 |
| --- | --- | --- |
| 0 到 30 秒 | 命名生态，选择源质印记 | 建立“这是我的潮池” |
| 30 秒到 2 分钟 | 主线首次展开，提示拖拽发光养料 | 让玩家知道目标和动作 |
| 2 到 5 分钟 | 主任务收起到状态栏并保持收起，生命材料增长 | 保持主画面干净 |
| 5 到 10 分钟 | 演化入口出现，查看第一道生命痕迹 | 把资源增长转成生命进展 |
| 10 到 20 分钟 | 第一种生命出现，写入图鉴与生命史 | 完成第一段生命史闭环 |

## 3. 创建生态

玩家先创建生态，而不是直接进入匿名存档：

```text
输入生态名称
-> 随机出现 3 个源质印记
-> 选择 1 个长期倾向
-> 创建后端存档
-> 浏览器保存 guestKey 和 saveId
-> 进入始源潮池
```

禁止：

- 注册、密码、手机号等正式账号流程。
- 多存档管理。
- 开局展示完整系统入口。

命名生态时允许加入一句极短远景，但必须立刻落回当前动作：

```text
从这片始源潮池开始，生命也许终有一天会望向群星。现在，先为它留下第一个名字。
```

## 4. 首次首页

首页只展示：

- 始源潮池。
- 自动展开的主线任务。
- 可拖拽的发光养料。
- 少量关键状态。
- 已解锁的底部入口。

首次引导文案：

```text
把发光的养料拖进水里。
```

补充小字：

```text
不同养料会改变潮池状态；很久以后，这些变化会成为生命史的开端。但现在只需要先让它活起来。
```

主线任务框停留一小会儿后缩放收起到状态栏，并记住收起状态。这个动画必须清晰表达“它被收起来了，可以点开”，不能像突然消失；玩家切回潮池时不应反复自动展开。

主线任务展开详情可以显示“这颗星球的生命史”远景条：

```text
生命诞生 -> 生态爆发 -> 海陆分化 -> 复杂生命 -> 意识萌芽 -> 文明初火 -> 星球危机 -> 群星生态
```

首局只高亮“生命诞生”，其余章节低饱和显示为未来痕迹。

## 5. 第一阶段反馈

每次阶段完成时给一句主题反馈：

```text
水里变得不一样了。
第一道生命痕迹出现了。
它们开始重复自己。
第一种生命被记录下来。
```

反馈应短、明确、世界内表达，不写成系统日志。

## 6. 演化首次进入

演化入口只在玩家接近首次节点时出现。

首次进入演化页时，玩家应看到：

- 已解锁节点：明亮稳定。
- 可解锁节点：明显高亮并轻微闪烁。
- 未解锁节点：可读但低饱和，像未来痕迹。
- 按钮使用自然动作文案，不用 `确认这一步`。

## 7. 物种首次发现

第一次发现物种时使用全屏或强焦点弹层：

```text
第一种生命出现了
这片潮池不再只是水和矿物。它有了自己的第一段生命史。
```

按钮：

```text
记录这段生命
```

确认后：

- 写入图鉴。
- 写入生命史。
- 如果相关入口首次解锁，给短奖励反馈。

## 8. 生命史与生态档案

首次游玩中不要让玩家看到后台式日志。

- 底部入口使用 `生命史`。
- 页面标题使用 `潮池记忆`。
- 重复操作合并成自然记忆。
- 空状态使用空白预言式文案：`潮池记忆尚未开始。若生命能留下第一道痕迹，这颗星球的故事就会有第一行。`
- `生态档案` 作为身份、成长记录、当前状态和存档信息入口。
- 重置本地存档只放在底部危险操作区。

## 9. 首局验收

- 玩家 3 秒内能说出：`我要养出第一只生命。`
- 玩家第一次操作前知道：`拖发光养料进水里。`
- 玩家完成第一阶段后知道：`潮池里出现生命材料。`
- 玩家进入演化页后能看出哪个节点已解锁、哪个可以点亮。
- 玩家不会在首局看到大段专业概念、后台日志或设置表单。
