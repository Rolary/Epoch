# 《生态纪元》第二章主线推进

本文档是第二章「生态爆发篇」的开发基准。第一章「生命诞生篇」已经完成基础闭环，第二章从第一种生命出现之后继续推进，不能反向破坏开局体验。

## 1. 主题

```text
主线：形成第一个小生态循环
```

玩家侧目标：

```text
这片潮池已经有了第一种生命。现在让它们分化、互相影响，并形成可以延续的生态循环。
```

阶段条：

```text
追逐光照 -> 分化角色 -> 形成循环 -> 面对失衡 -> 留下生态性格
```

## 2. 设计边界

- 第二章必须承接第一章留下的物种、源质印记、演化倾向、生态事件和生命史。
- 新内容重点是“物种之间开始互相影响”，不是新增更多资源面板。
- 玩家仍是观察者和引导者，不能直接指定某个物种必然出现。
- 首页仍以潮池主场景、当前主线、少量关键状态和可操作对象为核心。
- 文明、意识和群星继续作为远景回响，不进入第二章玩法系统。

## 3. 核心阶段

| 阶段 | 玩家理解 | 核心目标 | 代表反馈 |
| --- | --- | --- | --- |
| 1. 追逐光照 | 生命开始寻找能量来源 | 从感光色素承接，推动早期光能利用 | 生命开始追逐光 |
| 2. 分化角色 | 生命不再只是单一种群 | 出现生产者、分解者、滤食者等早期生态角色 | 潮池里出现不同分工 |
| 3. 形成循环 | 角色开始互相喂养或制衡 | 让至少一组生态组合产生可见反馈 | 第一个小循环接上了 |
| 4. 面对失衡 | 生态不是永远稳定 | 用事件表现爆发繁殖、浑浊缺氧、分解层扩张等取舍 | 繁盛也会带来压力 |
| 5. 留下生态性格 | 选择开始被生命史归纳 | 总结潮池倾向，如稳定循环、突变爆发、共生网络、极端适应 | 这片潮池有了自己的生态性格 |

## 4. 玩法与界面

- 图鉴从“记录物种”升级为“看见物种作用”，物种卡要展示生态角色、主要影响和与其他角色的关系。
- 生命史开始归纳重复生态现象，不逐条堆叠操作日志。
- 生态事件从潮池现象取舍升级为生态平衡取舍，每个选项都必须用世界内语言解释代价。
- 主线任务文案必须始终回答：`我现在怎样让潮池形成第一个小生态循环？`
- 第二章可以增加生态组合提示，但不能把首页变成全量生态网络图。

## 5. 暂不引入

- 正式文明系统。
- 多地图大世界。
- 真实 AI 服务。
- 正式账号、多设备同步、分享。
- 复杂后台统计或 Prisma。
- 完整食物网模拟器。

## 6. 验收标准

- 玩家完成第一章后，能自然理解下一步不是“重新养生命”，而是“让已有生命形成生态”。
- 至少三类早期生态角色可被发现或识别。
- 至少一组生态组合能产生明确的世界内反馈。
- 至少一个生态平衡事件让玩家做出有代价的取舍。
- 生命史能归纳潮池生态性格。
- 第二章结尾玩家能复述：

```text
这片潮池已经不只是有生命，而是有了自己的生态循环。
```
