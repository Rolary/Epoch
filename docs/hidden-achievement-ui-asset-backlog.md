## 风格约束

- 保持现有潮池的生物、矿物和水纹质感，不做成独立成就系统的奖杯图标。
- 不直接复刻外部作品角色、Logo、字体、UI 或标志性色块组合。
- 透明边缘需要适配深色潮池背景，移动端缩小到 38px 时仍能辨认轮廓。
- 动效纹理只短暂出现，不成为首页常驻装饰。
