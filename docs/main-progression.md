# 《生态纪元》第一阶段主线推进

本文档锁定第一阶段线性主线，防止游戏变成无主次的控制面板。第一阶段只做「生命诞生篇」。

## 1. 主题

```text
主线：养出第一只生命
```

玩家侧目标：

```text
这片潮池还没有生命。先让它拥有足够的材料、痕迹和延续能力。
```

阶段条：

```text
加入养料 -> 留下痕迹 -> 学会延续 -> 发现生命
```

## 2. 阶段总览

| 阶段 | 玩家理解 | 核心目标 | 代表反馈 |
| --- | --- | --- | --- |
| 0. 创建生态 | 这是我的潮池 | 命名生态，选择源质印记 | 潮池被唤醒 |
| 1. 让潮池活过来 | 死水开始有生命材料 | 拖入发光养料，积累生命材料 | 水里变得不一样了 |
| 2. 发现生命痕迹 | 结构开始稳定留下 | 查看并点亮首次演化 | 第一道生命痕迹出现了 |
| 3. 让生命学会延续 | 结构开始重复自己 | 解锁自复制链 | 它们开始重复自己 |
| 4. 选择延续倾向 | 复制开始分叉 | 在高保真复制 / 错误保留 / 断裂繁殖中留下一个倾向 | 潮池开始拥有性格 |
| 5. 等待第一种生命成形 | 反应被边界包裹 | 解锁膜泡 / 原初细胞并发现物种 | 第一种生命被记录下来 |
| 6. 光合作用前夜 | 生命开始追逐光照 | 接近感光色素或光合作用 | 下一段生态分支即将出现 |

## 3. 首页任务展示

主线任务卡不应长期挤占主画面：

- 首次进入时短暂展开，告诉玩家当前目标和动作。
- 几秒后通过清晰缩放动画收回状态栏，并记住收起状态，切回潮池时不反复展开。
- 收起后只保留阶段名、短目标和进度。
- 点击状态栏可展开，再点可收起。

任务卡始终保留一句主题：

```text
你正在把这片潮池养成生命的起点。
```

## 4. 第一阶段文案

标题：

```text
让潮池活过来
```

描述：

```text
把发光的养料拖进水里，让这片死水开始出现生命材料。
```

补充说明自然显示，不加「专业概念」前缀：

```text
潮池正在积累有机质、能量和矿物质。
```

进度：

```text
生命材料 0/20
```

首次引导只出现一条操作文案：

```text
把发光的养料拖进水里。
```

小字：

```text
不同养料会改变潮池状态，也会让低稳定的潮池慢慢回稳；但现在只需要先让它活起来。
```

## 5. 演化阶段文案

第二阶段：

- 标题：`发现第一道生命痕迹`
- 描述：`水里开始出现反复留下的结构。靠近它，让潮池进入下一步。`
- 补充：`有机物正在富集，复杂分子开始稳定存在。`
- 入口提示：`查看生命痕迹`

第三阶段：

- 标题：`让生命学会延续`
- 描述：`一些结构不只是出现一次，它们开始尝试复制自己。`
- 补充：`自复制链让生命从偶然反应走向可延续结构。`

延续倾向阶段：

- 在自复制链之后出现互斥分支。
- `高保真复制`：复制更稳，突变更谨慎。
- `错误保留`：突变更大胆，潮池更容易波动。
- `断裂繁殖`：旁支谱系更容易留下痕迹。
- 玩家只需要理解“这会改变潮池后来的生命性格”，不展示完整数值公式。

第四阶段：

- 标题：`等待第一种生命成形`
- 描述：`当材料、复制和稳定环境同时具备，第一批小生命就会出现。`
- 补充：`膜泡和原初细胞把反应包裹在边界里。`

第一次发现物种弹层：

- 标题：`第一种生命出现了`
- 描述：`这片潮池不再只是水和矿物。它有了自己的第一段生命史。`
- 小字：`已写入图鉴。物种会影响后续生态。`
- 按钮：`记录这段生命`

## 6. 演化页交互

- 原来的硬按钮文案 `确认这一步` 不再使用。
- 使用更自然的动作文案，例如 `点亮这道痕迹`、`让它延续`、`记录这个跃迁`。
- 已解锁节点保持明亮稳定。
- 可解锁节点需要闪烁或脉冲提醒，底部小黄点也同步提醒。
- 未解锁节点不能暗到看不清，应显示为低饱和、半透明、仍可阅读的未来痕迹。

## 7. 生命史与生态档案

- `日志` 玩家侧改为 `生命史`。
- 页面标题为 `潮池记忆`。
- 重复操作不逐条堆叠，合并为自然描述。
- `设置` 玩家侧改为 `生态档案`。
- 重置存档只放在底部危险操作区。

## 8. 验收标准

- 新玩家 3 秒内能复述目标：`我要养出第一只生命。`
- 第一次操作前知道动作：`把发光的东西拖进水里。`
- 完成第一阶段后知道变化：`潮池里出现生命材料 / 生命痕迹。`
- 首页、演化页、物种发现弹层、生命史和生态档案都使用玩家侧表达。
- 专业词只作为自然补充，不以前缀标签压住主目标。
- 首次随机事件以潮池现象承接，让玩家通过选择和生命史反馈发现生命史分支，而不是看到后台规则表。
