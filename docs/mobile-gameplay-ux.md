# 《生态纪元》移动端玩法与 UI 约束

移动端体验应像一款可玩的放置手游，而不是资源控制面板。第一章界面基线必须服务于一个目标：让玩家养出第一只生命。第二章完成基线在此基础上让已有生命形成小生态循环，但不能把首页改成资源控制面板。

## 1. 信息层级

首页优先级：

1. 活着的潮池场景。
2. 当前主线状态。
3. 可拖拽的发光养料。
4. 少量关键资源或状态。
5. 已解锁入口。

第二章可以增加生态角色、生态组合和生态平衡提示，但它们必须排在潮池场景、当前主线和主操作之后。

离线回归若形成持续水势，弹层需要用一句完整的世界内叙述说明“发生了什么、影响什么、还会持续多久”。回到首页后只保留一枚紧凑状态签，显示水势名、资源影响和倒计时；它不能扩展成新的常驻资源面板。

未收取养分最多积累 5 小时。超过上限时不再继续增长，回归弹层用“潮池的养分已经盛满”代替超长离线时长，首页主收集入口显示“潮池已满”。

不在首页长期展示：

- 全量资源表。
- 全量环境参数。
- 大段专业解释。
- 多个并列系统卡片。
- 后台式日志列表。

## 2. 主操作

第一章主操作是：

```text
把潮池周围的发光养料拖进水里。
```

交互要求：

- 发光养料要有入场和出场效果，不能突然出现或消失。
- 不同颜色养料可以影响不同状态，但开局只强调“先让它活起来”。
- 紫色和金色印记可以更稀有、更醒目，但不能让玩家误以为必须等稀有物才能推进。
- 拖入后要有水面、粒子或短反馈，表示潮池发生变化。

整体动效原则：

- 游戏内操作尽量用动画承接状态变化，不直入直出。
- 常规动作使用短、轻、可重复的反馈；解锁、奖励、危险和首次引导可以使用更强的动效。
- 新入口出现、弹层打开关闭、节点点亮、养料入水、生态干预反馈都必须有明确但不拖沓的过渡。
- 非必要动效必须尊重 reduced motion 设置。

## 3. 主线任务框

任务框不能长期挤占主画面。

行为：

- 首次进入自动展开。
- 展示几秒后通过缩放动画收回状态栏。
- 收起状态保留关键信息，例如阶段名和进度。
- 每次浏览器打开或刷新后首次进入潮池时自动展示一次；自动收起后，同一页面会话内玩家切回潮池时不反复展开。
- 玩家点击可展开，再点可收起。

文案原则：

- 大字说玩家目标。
- 小字只做自然补充。
- 不使用 `专业概念：`、`系统名：` 等设计者前缀。
- 文明、意识和群星只能作为短远景出现，不能挤占主线目标或拖拽操作。
- 主线展开态可显示低饱和远景条，但必须保持紧凑，不能遮住潮池主场景。

## 4. 底部入口

底部入口渐进出现：

```text
首页 -> 演化 -> 图鉴 -> 遗产 -> 生命史 -> 档案
```

命名要求：

- `日志` 改为 `生命史`。
- `设置` 改为 `档案` 或页面内 `生态档案`。
- 入口不是后台功能名，而是玩家理解的世界内入口。

新入口引导：

- 弹层只说明这个新能力在世界内意味着什么，以及它会怎样影响潮池。
- 不使用“屏幕右下角”“底部按钮”“点击某个栏位”等界面位置描述。
- 同一轮解锁多个入口时，使用串行导览队列：一次只弹一个奖励弹层，玩家亲自打开当前新入口后，再展示下一个。
- 玩家点“前往”后，由遮罩和高亮指向新入口，让玩家自己打开一次。

## 5. 演化页

节点状态：

- 已解锁：明亮、稳定、可信。
- 可解锁：高亮、脉冲或闪烁，下方提醒点同步强调。
- 未解锁：低饱和但可读，不要暗到像不可用错误。

按钮文案：

- 不用 `确认这一步`。
- 根据节点语义使用 `点亮这道痕迹`、`让它延续`、`记录这个跃迁` 等自然说法。

## 6. 生命史

生命史不是系统日志。

- 入口：`生命史`。
- 页面标题：`潮池记忆`。
- 空状态：`潮池记忆尚未开始。若生命能留下第一道痕迹，这颗星球的故事就会有第一行。`
- 重复操作合并为自然描述，例如：
  - `潮池连续吸收了几次能量闪光，水面变得更活跃。`
  - `矿物颗粒多次沉入池底，新的附着面正在增加。`
  - `潮水反复带回养料，生命材料正在富集。`
- 物种发现、纪元推进、遗产沉淀、印记获得保持独立关键记忆。

## 7. 生态档案

生态档案替代传统设置页。

分组：

- 潮池身份：生态名称、当前纪元、生态倾向。
- 成长记录：演化节点、物种、遗产、源质印记。
- 当前状态：主要资源、稳定性、突变倾向、生命成形进度。
- 首页资源收纳在顶部潮池状态栏中，保留图标与数值；名称只在点击对应资源后短暂展开，避免常驻文字挤压潮池画面。
- 限时水势以状态图标和动态上下箭头表达增益、减益或混合影响，点击后再展开水势名称与具体影响；减少动态效果开启时箭头保持静态。
- 潮汐养分未达到可收获状态时，主操作折叠为单个收获图标；点击只提示预计还需等待多久，不再向玩家暴露内部资源阈值。
- 生态干预中的“生态爆发”章节入口只在第二章解锁后出现，第一章期间不展示禁用占位。
- 存档信息：游客印记、存档 ID、最近更新时间。

重置本地存档必须放到底部危险操作区，文案明确且需要二次确认。

## 8. 移动端验收

- 单手可完成首次拖拽。
- 主线收起后，潮池仍是视觉中心。
- 文字不溢出按钮、卡片或状态栏。
- 专业词不抢占玩家目标。
- 首页、演化、图鉴、遗产、生命史、生态档案都不像后台管理系统。
- 第二章新增生态信息不遮挡潮池，也不要求玩家阅读复杂表格才能继续推进。
- 六项状态全部出现时允许状态栏横向收纳，但首页不得产生页面级横向滚动。
- 生态干预优先展示当前可发生的水中回响；未形成的长期组合最多显示一条世界内提示，不常驻精确倍率攻略表。
- 第二章完成态主目标保持为“第一阵往复已经接上”，完成提示可直接进入潮池记忆。
