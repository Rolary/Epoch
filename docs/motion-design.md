# 《生态纪元》动效设计与实现规范

本文档定义潮池首页、React 界面与关键叙事反馈的动效语言。动效的目标不是装饰界面，而是让玩家感到潮池持续活着、操作确实改变了水面、生态状态正在留下痕迹。

## 1. 动效层级

| 层级 | 用途 | 典型时长 | 强度 |
| --- | --- | --- | --- |
| 环境呼吸 | 静止时维持生命感 | 3-16 秒循环 | 极轻，不抢操作 |
| 操作前馈 | 告诉玩家对象已被抓取、可被潮池吸收 | 80-220 毫秒 | 清晰、即时 |
| 操作结果 | 表现养料入水、收取、生态干预 | 300-900 毫秒 | 中等，可重复 |
| 状态跃迁 | 节点点亮、物种发现、入口解锁 | 500-1200 毫秒 | 较强，只播放一次 |
| 危险与稀有 | 失衡、异常脉冲、隐秘潮痕 | 600-1800 毫秒 | 最强，低频使用 |

任何常驻循环都不能比当前主操作更醒目。强闪烁、震屏、快速缩放只用于低频的危险或稀有反馈。

## 2. 静止时动效

### 2.1 潮池主场景

- 水体以低幅透明度变化形成缓慢呼吸，不能像按钮一样持续催促。
- 焦散纹、光束、藻膜与水中云团使用不同周期漂移，避免所有元素同步摆动。
- 已出现的微生物在池内缓慢游动，接近边缘后自然回转。
- 第二章生态角色直接改变场景：生产者表现受光薄膜，分解者表现池底沉积活动，滤食者表现水流筛纹，小循环表现多层回流。
- 画面上方保留极慢的自然光扫过，外缘暗角做低幅呼吸，以维持水体深浅变化。
- 发光养料拥有轻微漂浮、轨道微粒和稀有度差异，但普通养料仍然足够明显。

### 2.2 HUD 与页面

- 首页 HUD 首次出现时从上下边缘轻量归位，之后保持稳定，不反复播放入场。
- 可收取养分使用慢速呼吸，不使用快速闪烁。
- 可点亮演化节点使用金色低幅脉冲；已点亮节点稳定常亮；未点亮节点不播放循环动画。
- 物种发现图像使用很轻的上下浮动和光晕变化，正文保持静止可读。
- 页面进入使用短距离上移与淡入，标题、说明、主体有 40-80 毫秒层级差。

## 3. 交互时动效

### 3.1 拖拽养料

1. 按下时养料在 80-150 毫秒内轻微放大，明确已经抓住。
2. 拖动时留下连续而渐细的同色拖尾，不用每帧随机闪点造成抖动。
3. 接近潮池时出现两层吸收边界和一条牵引线，强度随距离增加。
4. 进入有效吸收范围后，边界呼吸幅度增强，让玩家在松手前知道操作会成功。
5. 未投入水中时，养料轻弹回稳定尺寸；不使用错误弹窗打断拖拽节奏。

### 3.2 养料入水

- 养料先向池心收束，再出现由内向外的椭圆水纹。
- 池面同步产生一次短促横向形变，表现水体被压入而不是只叠加粒子。
- 外围微粒向池心汇入，随后少量结果粒子向外散开，形成“吸入 -> 反应”的完整因果。
- 普通正向结果沿用养料色；负向结果转为红色并可轻震屏；稀有结果转为金色并增加水纹和光束。
- 连锁吸收仍逐个播放，但单次反馈控制在 900 毫秒内，避免遮住下一次操作。

### 3.3 收取、生态干预与导航

- 可点击按钮按下时缩小 1.5%-8%，松手后恢复，触屏也能感知确认。
- 收取成功继续使用世界内文字反馈，资源变化由短上浮提示承接。
- 生态干预保留中心爆发、环形扩散与图标收束，结果文案在主反馈之后出现。
- 底部导航按下时下沉并缩小，当前入口稳定高亮；新入口和可演化提醒才允许持续脉冲。
- 抽屉、半屏与弹层必须有对应关闭动画，不能只在打开时有过渡。

### 3.4 演化与发现

- 节点点亮后播放一次亮度提升、轻微回弹和横向光扫，随后落到稳定的已解锁状态。
- 物种发现、隐秘潮痕和系统入口使用较强的首次演出，但关闭后不在首页重复播放。
- 多个叙事反馈继续进入串行队列，前一条完成后再播放下一条，避免动画互相覆盖。

## 4. Reduced Motion

当系统设置 `prefers-reduced-motion: reduce` 时：

- CSS 动画和过渡缩短到近乎即时，只保留最终视觉状态。
- Phaser 的水体呼吸、漂游、光束和焦散降到原幅度或速度的约 10%-20%。
- 取消震屏、密集粒子、持续旋转与多层连续水纹。
- 拖拽吸收边界、颜色变化、状态高亮继续保留，因为它们承担交互信息。
- 进度、解锁和危险不能只依赖动画表达，必须同时有颜色、形状或文案状态。

## 5. 性能边界

- 首页常驻动画由 Phaser 与 CSS 原生能力承担，不新增通用动效运行时。
- Phaser 高频绘制按 80-120 毫秒节流；瞬时 Graphics、粒子和 tween 完成后立即销毁。
- 同屏可拖拽养料维持最多 2 个，避免低端移动设备出现过量发光混合。
- 页面动效只使用 `opacity`、`transform` 和有限的 `filter`，避免持续触发布局计算。
- 若未来出现复杂时间轴、共享元素转场或骨骼角色动画，再分别评估 Motion、GSAP 或 Rive；不能只为按钮淡入引入额外包。

## 6. 验收清单

- 静止观察 20 秒，潮池有生命感但没有任何常驻元素持续抢焦点。
- 单手拖拽时，按下、靠近水面、投入、结果四个阶段都能被视觉区分。
- 正向、负向、稀有三类入水结果在不读文字时仍可辨认。
- 页面、弹层、抽屉、节点和新入口的出现都不是瞬间切换。
- 连续操作时动效不阻塞输入、不改变按钮尺寸、不造成页面横向滚动。
- 开启减少动态效果后，所有功能仍可理解，且没有震屏、强闪烁或长循环位移。
